# Согласие и аналитика

## Актуальное поведение, 21 ноября 2026

Счётчик: Яндекс Метрика 114414864. Общие файлы: `assets/site-consent.js` и `assets/site-consent.css`.

Окно «Аналитика сайта» содержит две кнопки, без галочек и подсказок о доступности. «Разрешить аналитику» сохраняет согласие на аналитические cookie и обработку данных для аналитики, затем подключает Метрику с Вебвизором. «Продолжить без аналитики», крестик и Escape сохраняют отказ. Сайт доступен при любом выборе. При повторном открытии для активного согласия вторая кнопка называется «Отключить аналитику»; крестик и Escape также отзывают согласие.

До разрешения Метрика и пиксели не загружаются. Выбор хранится в localStorage на текущем origin 180 дней и синхронизируется между вкладками. При недоступном хранилище следующая страница снова спрашивает выбор. Версия согласия повышена до 2 из-за изменения текста и способа принятия: предыдущий выбор версии 1 не включает аналитику, посетитель увидит обновлённое окно один раз.

«Настройки аналитики» находится в подвале, рядом с именем и политикой, без плавающей кнопки. На широком экране элементы расположены в одну строку, на узком разрешён перенос. При отсутствии footer общий компонент создаёт его. Закрытие окна не прокручивает страницу к подвалу.

Отзыв вызывает destruct, очищает доступные cookie с префиксом _ym_ и перезагружает страницу для удаления обработчиков и Вебвизора. Cookie других доменов недоступны к удалению; уже переданные данные не удаляются.

## Оформление

Ширина окна до 360 px, отступы 20/18 px, текст 13 px и пояснение 12 px. Кнопка разрешения терракотовая `#9e422f`, цвет взят из примера пользователя; кнопки прямоугольные с небольшим скруглением, высота не меньше 44 px. Тёмный фон окна сохранён. Политика опубликована на `/policy/`.

## Проверки

`node --check assets/site-consent.js`, `node scripts/integrate-consent.cjs`, `node scripts/test-consent.cjs`, `git diff --check`. Проверяются фактический JS в VM: отсутствие трекера до разрешения, принятие, сохранение отказа, крестик/Escape, настройки в footer, повторный запрос старой версии, отзыв и синхронизация вкладок, повреждённые данные и недоступное хранилище. Проверяется охват всех самостоятельных HTML и отсутствие Google Fonts/безусловных пикселей. После добавления страницы или запуска генераторов выполняйте интегратор.

## Публикация

Автоматическая публикация не настроена. При публикации нужно сохранить действующий релиз целиком, заменить только общие файлы, обновить версии их URL во всех серверных HTML и сохранить остальные серверные страницы. Исходники основной ветки и действующий сайт отличаются дополнительными страницами; не заменять сайт полным снимком Git без сверки.
