# Портфолио Галины Ершовой

Статические прототипы главной страницы. Текущий согласованный вариант — `index.html` (также доступен как `constructor.html`): светлый фон, терракотовый акцент, проекты и интерактивные этапы работы.

## Запуск

Нужен Node.js. Установка зависимостей и сборка не требуются.

```sh
node server.cjs
```

Открыть http://127.0.0.1:4179/constructor.html. Сервер доступен только локально. Если порт уже занят открытым прототипом, сначала остановить тот сервер.

## Варианты

- `index.html` и `constructor.html` — текущий терракотовый вариант
- `blue.html` — исходный синий вариант
- `green.html` — зелёный вариант
- `media.html` — Navy
- `palettes.html` — отдельная страница прямых ссылок на варианты для A/B-тестов. Параметр `?palette=blue|green|navy` меняет только палитру основного терракотового макета; без параметра используется терракотовая палитра. Старые концепции доступны по прямым ссылкам.
- `*-before-*.html` и `previous-backgrounds/` — сохранённые предыдущие версии

Общие стили и поведение находятся в `styles.css` и `app.js`. Файлы `constructor-*.css` и `constructor-*.js` отвечают за текущий вариант. Фрагмент этапов работы — `constructor-process.html`.

Генераторы `*.mjs` сохранены как исходные инструменты создания вариантов. Они перезаписывают HTML; не запускать их для обычного просмотра. `node constructor-update.mjs` пересобирает терракотовую страницу из текущего `media.html`, существующего hero в `constructor.html` и модулей `constructor-*`.

## Состояние

Основная терракотовая страница опубликована на `galaershova.ru`; исходные файлы остаются в этой ветке. Примеры задач и этапы переключаются автоматически, доступен ручной выбор и учитывается режим уменьшенной анимации. Варианты палитры открываются только по прямым ссылкам. Автоматическое распределение посетителей, учёт групп и метрик A/B-теста не включены; запускать их только по отдельной команде. Страницы содержат `noindex,nofollow`; ссылки на проекты могут вести на действующий сайт или внешние демо.

## Мобильная версия

Для экранов до 540 px увеличены ссылки на проекты и почту, уплотнены иллюстрации карточек и отступы. Кнопка действия в окне проекта остаётся видимой, пока прокручивается описание. Проверены ширины 320 и 390 px без горизонтальной прокрутки.
