## Страница Deal Copilot

Кейс доступен по маршруту `/projects/deal-copilot/`. Из блока «Корпоративная база знаний» на активной главной `index.html` и в варианте `constructor.html` ведёт отдельная ссылка «Кейс Deal Copilot»; карточка самого проекта в `constructor.html` тоже ведёт на эту страницу. Исходник лендинга — `projects/deal-copilot/index.html`. При обновлении карточек сохраняйте те же адреса в обоих HTML-файлах и `constructor-projects.mjs`.

Светлая версия использует лесной зелёный акцент приложения. Изображения в `projects/deal-copilot/images/` — скриншоты локального демостенда со светло-зелёной темой и условными данными. На лендинге «КП под контролем» упрощён текст, этапы последовательно подсвечиваются раз в 2 секунды (с учётом reduced motion), единственная кнопка первого экрана открывает демо `https://deal-copilot.tools01.ru/` (HTTP 401 без логина и пароля). Прежние варианты страницы сохранены в `previous-backgrounds/deal-copilot-blue.html` и `previous-backgrounds/deal-copilot-dark.html`; старые скриншоты — в `previous-backgrounds/deal-copilot-dark-images/`.

У опубликованных проектных лендингов («КП под контролем», BI, рекомендации, Ask&Learn) в шапке единый знак «г.» со цветом точки из локальной палитры и ссылкой на главную. `projects/ask-study/index.html` — копия опубликованной страницы Ask&Learn, добавленная в эту ветку для сохранения правки логотипа.

Статические прототипы главной страницы. Текущий согласованный вариант — `constructor.html`: светлый фон, терракотовый акцент, проекты и интерактивные этапы работы.

## Запуск

Нужен Node.js. Установка зависимостей и сборка не требуются.

```sh
node server.cjs
```

Открыть http://127.0.0.1:4179/constructor.html. Сервер доступен только локально. Если порт уже занят открытым прототипом, сначала остановить тот сервер.

## Варианты

- `constructor.html` — текущий терракотовый вариант
- `index.html` — исходный синий вариант
- `green.html` — зелёный вариант
- `media.html` — Navy
- `*-before-*.html` и `previous-backgrounds/` — сохранённые предыдущие версии

Общие стили и поведение находятся в `styles.css` и `app.js`. Файлы `constructor-*.css` и `constructor-*.js` отвечают за текущий вариант. Фрагмент этапов работы — `constructor-process.html`.

Генераторы `*.mjs` сохранены как исходные инструменты создания вариантов. Они перезаписывают HTML; не запускать их для обычного просмотра. `node constructor-update.mjs` пересобирает терракотовую страницу из текущего `media.html`, существующего hero в `constructor.html` и модулей `constructor-*`.

## Состояние

Сохранён локальный прототип после выравнивания пяти этапов по всей ширине. Автопереключение этапов, ручной выбор, пауза и режим уменьшенной анимации реализованы. На `https://galaershova.ru/` сервер `gala-msk` отдаёт `index.html`; `constructor.html` остаётся отдельным вариантом. Прежний сайт снят с публикации; его релиз сохранён на сервере для отката. Остальные варианты этого репозитория доступны по именам HTML-файлов. Страницы и конфигурация Nginx содержат `noindex,nofollow`; это отдельное решение о видимости для поисковых систем. Ссылки на внешние демо сохраняются.
